# Pitch

| File | What it is |
|---|---|
| [SPEAKER-NOTES.md](SPEAKER-NOTES.md) | The 5-minute script with timings, and the checklist before going on stage |
| [deck.html](deck.html) | Offline copy of the deck: open it in any browser. Arrows, space or click to move, **N** for speaker notes, **F** for fullscreen, `#7` in the address jumps to slide 7. Fonts load from Google Fonts when online and fall back to Georgia/Arial offline |
| [slides/](slides/) | Slide sources (one HTML section per slide, plus `deck.json` for the order) |
| [build-deck.py](build-deck.py) | Rebuilds `deck.html` from `slides/`: `python pitch/build-deck.py` |

**Online deck:** https://claude.ai/artifact/Phi1TiNUejNtNqet9111UR (editable, downloadable as PDF or PowerPoint from its Share › Export menu). It is private to the account that created it until shared from its Share menu.
